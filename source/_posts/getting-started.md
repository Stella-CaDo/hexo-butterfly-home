安装根目录和首页依赖后运行 `npm run build`，再运行 `npm run server`。

<!-- more -->

修改 `_config.yml` 和 `_config.butterfly.yml` 设置博客，修改 `apps/homepage/profile.json` 设置个人主页。所有占位资料都需要你自行填写。

部署默认关闭。阅读 README 后，填写本机的配置覆盖文件，再手动部署到你自己的静态服务器。
